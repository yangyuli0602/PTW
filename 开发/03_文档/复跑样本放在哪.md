## 为什么单独立这一条

2026-11-13 工作区精简时整个 `tmp/` 被搬到了工作区外的备份目录，
之后复跑一直去那里指路径——**备份区被当成工作区用**，别人接手找不到数据，
而备份区按定义是回滚点，不该当日常数据源。

搬回工作区后：`--data-root` 指 `账表/`，**不需要 `--only`** 排除上期底稿
（以前指上一级时，两份 SWP 会被算成"未命中规则"，把退出码从 6 顶到 4）。

**红线（2026-11-13 起）**：只允许在 `01_PTW框架` 内工作。任何脚本、文档、命令
都不许写工作区外的绝对路径——`check_structure.py` 已把它做成提交拦截。

**备份区已不存在**：11-13 那批搬走的 `tmp/` 当天下午被清理掉了，
`01_测试/清洗复跑样本/` 现在是这两套账表**唯一的一份**，别删。

## 一句话

复跑不碰备份区。要重跑，直接：

```bash
python 01_测试/自动回归/run_clean.py \
  --data-root "01_测试/清洗复跑样本/2026瑞云_202601-09/账表" \
  --recipe "04_归档/01_PTW项目级配置文件/2026瑞云PTW配置文件/瑞云清洗配方_20261112.json" \
  --std-accounts "04_归档/01_PTW项目级配置文件/2026瑞云PTW配置文件/瑞云_客户科目表_std_accounts.json" \
  --work-dir tmp/瑞云复跑_20261113 --port 8899
```

海柔把 `瑞云` 换成 `海柔`、期间换 `202601-06` 即可。
