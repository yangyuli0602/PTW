# 04 · Cutoff 及样本池（样本池-cut off + VC&VD.01.4）

> 截止性测试看**资产负债表日前后各 30 天**（可改），TOD 看全年。
> 两者底料完全一样，所以池子只算一次：`样本池-cut off` 是全量底料，01.4 从里面挑。

## 2. 剔除判定：四步，顺序不能乱

```
① 结转损益  →  ② 科目性质（薪酬 / 四类折旧摊销 / 租赁）  →  ③ 预提冲销  →  ④ 负值  →  ⑤ 其余「否」
```

### ① 结转损益

判定：**凭证内含 4103/4104 科目** 或 摘要精确匹配「结转本期损益 / 结转损益 / 期间损益结转」。

- 不能用裸「结转」二字：`结转----确认上市费用` 是真实借方费用，按关键字删会少一块
- 必须在最前面：结转贷方金额往往比任何真实业务都大，不先排，池子里全是结转，截止性就成了测结转

### ② 科目性质（去掉「销售费用_/管理费用_」前缀后再判）

判定顺序固定：**股权激励 → 折旧摊销 → 薪酬 → 租赁**。反了会归错（股份支付常写成「员工股权激励薪酬」）。

| 类 | 关键词 | 归到 |
|---|---|---|
| 股权激励 | 股权激励、股份支付、限制性股票、期权、员工持股、限制性股份 | 工资薪酬 |
| 折旧摊销 | 折旧、摊销 | 含「使用权」→使用权资产折旧费；含「无形资产」→无形资产摊销费；含「长期待摊/待摊」→长期待摊费用摊销费；其余→固定资产折旧费 |
| 薪酬 | 薪酬、工资、奖金、提成、社会保险、公积金、福利、职工教育、工会、离职补偿、辞退、劳务、董事、监事、年金、补贴、津贴、社保、人力成本、年终奖 | 工资薪酬 |
| 租赁 | 租赁 | 租赁费 |

四类折旧摊销必须按**资产类型**拆开（TOD 模板分开列），不能并成一个「折旧摊销」。

### ③ 预提冲销配对

同主体 + 同科目代码 + 同|金额|，一正一负，配成一对，两侧都归「预提费用（含预提和冲销）」。

- **只在尚未被排除的行之间配**。否则「借方 1 万 / 结转贷方 1 万」会被当成冲销对，一口吃掉大半池子
- 金额下限 100 元，避免 0.04 元尾差被标成预提
- 净额必然为 0，这是正常结果，不是「没有预提费用」

### ④ 负值（必须最后）

性质都归完之后，**剩下说不出来源的负数**才进「负值」。

顺序反了会怎样：一笔「折旧 −5 万」先被负值吃掉，a 段的固定资产折旧费就少一块，TOD 的 1.2 剔除表永远对不上 G29。

### ⑤ 其余 → 「否」

## 3. 一份分类，两处共用

池子 N 列这套取值同时服务 01.4 和 TOD：

```
TOD 的 8 个剔除桶  ← SUMIFS 直接吃 N 列
01.4 的样本筛选     ← 只取 N = "否"
```

**不许再维护第二套「TOD 分类」列**。改分类口径只改这一处，两边同时生效；否则会出现
「截止性说有 2,658 行、TOD 说 2,700 行」这种两边都对不上的局面。

## 4. 01.4 页结构

| 区 | 行 | 内容 |
|---|---|---|
| 抬头 | 1~6 | 标题、执行截止性测试、返回汇总页 |
| 表1 | 8~10 | B9 标签 / **B10 = 前后天数（默认 30）** / C10 依据 / D10 开始日 / E10 结束日（公式） |
| 表2 | 12~15 | 样本策略叙述（合并区 B13:E15） |
| 表3 | 17 起 | 表头 21~23；本期标题 24、明细 25~29；日后标题 30、明细 31~35 |

### 4.1 表3 的取样条件（三条同时满足）

1. `N 列 = 否`
2. `资产负债表日 − 30 ≤ 日期 ≤ 资产负债表日 + 30`
3. `|金额| ≥ 门槛`（门槛 = TE×50%，与 BKD 的 C22 同源）

**金额按绝对值判**：大额冲减（负数）恰恰是要看的，不能因为小于门槛就跳过。

### 4.2 分两段

按**凭证日期**与资产负债表日比：`≤ 日` 进「本期资产负债表日前记录的交易」（I 列打 √）；
`> 日` 进「日后」（J 列打 √）。

- 本期区容量 5 行（25~29），日后区容量 5 行（31~35）；超出先在日后标题前整行插入，再补样式
- 人工列（F 交易凭据名称 / G 编号 / H 交易发生日期 / K EY Works）留空，**不标黄**（整列空，标黄等于刷屏）
- L 列备注写摘要前 80 字，便于人快速认

基准：测试期 2026-08-31 ~ 2026-10-30，本期 5 笔（B25~B29），日后 0 笔。

### 4.3 表2 的策略文字必须引用实际条数

模板这块原本空白，项目组每次手写。工具生成时把数字换成**实际写进表3 的条数**：

> 经分析，剔除薪酬、折旧等已在其他底稿测试的费用明细后，我们基于定量和定性两个维度确定关键样本。
> 定量方面……定性方面……
> 按照如上标准，我们在资产负债表日前识别到 **N** 个测试样本，在资产负债表日后识别到 **M** 个测试样本。

- N/M 必须是本次真实写入条数，不能写死 5/5
- 合并区 B13:E15 只有 3 行高，长文本会被盖住，要把 13/14/15 行高撑到 30

## 5. 掐掉「本期起点之前」的行

账套常把上一年 12 月的计提 + 结转一起带进来。结转那一半会被判「结转损益」剔掉，
**计提那一半留在池子里**，TOD 的 1.1 总体就会比 BKD 合计多出一块。

做法：按「期间起月 1 日」把 `日期 < 期初` 的行整行丢弃，并记下丢弃条数（报告里给 `beforePeriod`）。

> 实例（瑞云）：正好 80,378.56（销售 25,477.87 / 管理 54,899.69），不掐 TOD 总体就比 BKD 多这一块。

## 6. 坑

| 现象 | 原因 / 处理 |
|---|---|
| 池子里一大半是结转 | 结转没先排，或只按摘要「结转」匹配（把 `结转----确认上市费用` 也删了） |
| 预提费用桶金额巨大、把样本吃光 | 配对冲时拿了「借方 + 结转贷方」配对；配对应只在未排除行之间做 |
| 折旧类金额归错桶 | 科目性质判定顺序反了，或没有按资产类型拆四类 |
| TOD G29 对不上 G31 | 一笔进了两个桶，或负值先于性质判定 |
| 01.4 表3 全是小数 | 门槛取了 0（TE 没写进 Lead C4） |
| 表3 大额冲减被漏掉 | 用金额而不是**绝对值**比门槛 |
| 表2 策略写 5 个、表3 有 7 行 | 数字写死了，要取实际写入条数 |
| 上一年 12 月计提混进本期 | 没按期间起月 1 日掐掉 |
| 外币主体的折算率看着不对 | 按 1 计了，要标黄并在报告里警告 |

## 13. 排除口径：回到关键词规则（V1.2.79 回退）

> 曾经的 V1.2.77 / V1.2.78 做过一版「排除Mapping」：单独一张配置表，
> 逐条（主体, 科目）人工指定是否排除，样本池 N 列再用 XLOOKUP 指向它。
> **V1.2.79 已整块撤掉**，判定回到代码里的关键词规则。

### 13.1 为什么回退

- 池子里 300+ 行，真正判错的只有关键词没覆盖到的少数科目；
  为这几个科目维护一张与 OAR 平行的第二张 mapping，每次生成都要人去比一遍，
  比错判本身的代价还大。
- 两张表长得一样（都是「主体|科目 → 某个值」），名字也只差两个字，项目组很容易改错表。
- N 列写成公式后，池子里的颜色仍按生成时的分类上色，改配置重算会出现
  「文本说「否」、颜色还是灰的」，解释成本高于收益。

### 13.2 现在的口径（唯一一条）

```
结转损益（凭证特征：4103/4104 + 摘要含结转损益）
  → 科目性质（cutoff_kind 关键词：股权激励 > 折旧摊销四类 > 薪酬；V1.2.80 起**租赁费不再排除**）
  → 预提冲销配对（同主体 + 同科目代码 + 同金额、一正一负）
  → 负值
  → 其余「否」
```

顺序不能动。`mark_exclusions(rows)` 没有第二个参数了，也不再读任何配置表。

### 13.3 想改怎么办

改 `程序/modules/bkd/expense_cutoff.py` 里的 `PAY_WORDS` / `DEPR_WORDS` /
`EQUITY_WORDS` 关键词表，或在 `cutoff_kind()` 里加分支 —— 改的是**规则**，不是某一版数据。
配置式做法（`--excl-map`、`body.excl_map`、`build_excl_map()`、`excl_map_from_sheet()`）
V1.2.79 起全部删除，调用会直接报参数错误，不会静默失效。

## 14. mapping 只剩两段：OAR 口径 + 公司简称（V1.2.79）

`口径Mapping` 现在只有两段，与 BKD 的 T 列 / 简称一一对应：

| 段 | 位置 | 内容 |
|---|---|---|
| 一、OAR 口径 Mapping | A5 表头起 | 主体\|科目 → OAR 口径 |
| 二、公司 Mapping（简称） | H5 表头起 | 主体 → 简称 |

**样本池的「是否排除」列改回写文本**（`样本池-TOD` / `样本池-cut off` 的 N 列）：
生成时按 13.2 的规则判定后直接落值，不再写成 XLOOKUP。改判定要重新生成。

一条硬约束：**OAR 口径列永远不留空**。留空时 BKD 的 T 列取回空白，OAR 页按口径
SUMIF 就把这一块漏掉 —— 表1 合计会比 BKD 合计小一截，而且是静默少（实测漏过 76 万）。
V1.2.80 起的取值顺序：AI 语义匹配（来源「由AI判断」）→ 规则推导（来源
「规则推导-待AI复核」，黄底，待跑 AI）。**不再出现「未匹配-待判断」**。

## 15. BKD 变动率不留空（V1.2.78）

`O 列（变动%）` 原来在分母为空时返回空串，整列时有时无，筛选和求和都要先判空。现在：

```excel
=IF(OR(M30="",M30=0),0,N30/M30)
```

配 `0.00%` 数字格式，没有上期数时显示 **0.00%** 而不是空白。
变动金额（N 列）仍留空——没有可比数时给 0 会让人误以为「没变化」，与「算不出来」是两回事。

## 16. 取数只取借方；租赁费不再排除（V1.2.80 → V1.2.82）

### 16.1 金额方向：贷方行根本不进池子

```sql
-- V1.2.79 及以前：一行内借贷相减
coalesce(debit,0) - coalesce(credit,0)              AS amt
-- V1.2.80：行内不相减，正常费用取借方全额
CASE WHEN coalesce(debit,0)<>0 THEN debit
     ELSE -coalesce(credit,0) END                   AS amt
-- V1.2.82：贷方行连行都不生成
WHERE acct_l1 IN (...) AND coalesce(debit,0) <> 0
```

**为什么必须走到第三步**：费用科目的贷方几乎全是月末结转（借本年利润 / 贷费用）。
V1.2.80 把它们当负数收进池子，整列加总必然抵成 0 —— 瑞云 1-9 月实测借方
38,362,151.70 与贷方 38,362,151.70 完全相等，池子合计 **−0.00**，3,995 行全部落在
「结转损益」桶里。样本按金额排序、按阈值挑关键项、负值分析的比例分母，全部建立在
这个 0 上，等于没有总体。改后池子 10,709 → 6,714 行，合计 **70,311,758.90**，
与 BKD「本期账面数」一分不差。

**负数没有一起排掉**：红字冲销记的是「借方负数」，仍是借方行，照旧进池子、进「负值」桶。
瑞云负值 743 行、表2 的「冲销预提 + 其他性质」合计与台账负借方一致。

两个连带事实（都已在说明里写明，不是差错）：

- 「结转损益」桶计数变 0 —— 结转那半边是贷方，本来就不在池子里；判定逻辑保留兜底。
- 预提冲销只在「正借方 vs 负借方」之间配对，瑞云仍有 201 对；若客户把冲回记在贷方，
  这个桶会只剩计提那一半。

`read_pool()` 是 TOD 池与截止性池的**同一份底料**，改一次两边同时生效。

### 16.2 默认排除项去掉租赁费

见 `03_TOD及样本池.md` §13.1。要点：短期/低价值租赁直接进费用、没有使用权资产底稿
可承接，一刀切排除会漏掉整类高金额业务；`KIND_RENT` 常量保留（模板 1.2 有那一行），
但 `cutoff_kind()` 不再返回它，池子里租赁相关科目归「否」，参与关键项与抽样。

实测：池子「否」从 2,607 条升到 2,658 条（多出的 51 条正是原先被排除的租赁费）。
