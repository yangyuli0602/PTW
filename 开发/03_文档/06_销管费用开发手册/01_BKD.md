## 2. 列结构（A~T，插两列之后的最终态）

| 列 | 名称 | 写法 |
|---|---|---|
| A | 简称 | 账簿→公司简称对照；是表3 SUMIFS 的匹配键 |
| B | 账套名称/账套编码 | 公司全称 |
| C | 总账科目编码 | 原样文本（`6601.025`、`56011801`，前导零不能丢） |
| D | 科目名称 | `销售费用_展会费` 形式，**表3 的 FOR BKD 要与它逐字一致** |
| E | 本期账面数 | 借 −（贷 − 结转损益贷）= 本期发生额 |
| F | 账表调整数 | 默认 0，人工填 |
| G | 本期未审数 | `=E+F` |
| H | 结构比 | `=G/合计G`，合计行 = 1 |
| I | 审计调整数（本期） | `SUMIFS(表3 F列, 表3 C列, 本行A, 表3 H列, 本行D)` |
| J | 本期审定数 | `=G+I` |
| K | 上期未审数 | 上年底稿的上期审定数（静态值，不是公式） |
| L | 上期调整数 | `IF(K="","",SUMIFS(表3 G列, 表3 C列, 本行A, 表3 H列, 本行D))` |
| M | 上期审定数 | `=IF(K="","",K+L)` |
| N | 变动金额 | `=IF(M="","",J-M)` |
| O | 变动% | `=IF(OR(M="",M=0),"",N/M)` |
| P | For X-ref | 按科目认底稿；认不出打 `/`，不标黄 |
| Q | 进一步调查（波动幅度） | 见 §5 |
| R | 进一步调查（定性） | 固定「否」 |
| S | Notes | NB 编号，必须与表2 的 `NBn：` 对应 |
| T | OAR 口径 | XLOOKUP 口径Mapping（主体\|科目 → 口径，科目名兜底） |

### 2.1 为什么是「插两列」

模板原本只有 K「上期审定数」。要做「上期未审 + 上期调整 = 上期审定」三段式，必须在 K 前插两列。
插列是**运行时做的**，模板文件不改。

**openpyxl 的 `insert_cols` 只搬格子和样式，不搬合并区、不搬列宽、不改公式。** 三样都要自己补：

1. 先按**旧坐标**解除受影响合并区（尤其表头 K28:M28 这类跨列合并），再插列；
2. 插完把新两列按右侧邻列逐格复制字体/填充/边框/对齐/数字格式——新列是「裸格」，不补就是白底黑字；
3. 表头区（含第 26~29 行）的合并区按**新坐标**重建；
4. 六列（变动金额/变动%/X-ref/Q/R/S/T）整体右移，模板里它们的公式要重写；
5. 列宽最后再钉一次（插列时的搬移会被后续设置覆盖）。

### 2.2 插列顺序的坑（V1.2.35 出过）

模板 `N28:N29`、`O28:O29` 是纵向合并，插列后模板里的「变动金额」「变动%」正好落进这块旧合并区。
如果**先插列再解合并**，清理函数会把成员格的值**和样式**一起清成 Normal，两格变空白且不报错。

> 刚性顺序：**按旧坐标解除合并 → 插列 → 逐格补样式 → 按新坐标重建合并 → 写值写公式。**

## 3. 数据行怎么来

- 一个键 = 主体 + 一级科目 + 科目全称。同一主体下多个账簿要合并（不是一行一个账簿）。
- 主体取 `company_name` → 退 `book_name` → 退「未标注主体」，与货币资金同口径。
- 金额 `_num` 只认「数字 + 千分位 + 货币符号 + 单位」，含文字返回空（不猜）。
- 排序：主体（按简称）→ 科目编码。上期匹配靠 `(规范化账簿名, 科目名称)` → 退 `("", 科目名称)`。

## 4. 合计与核对段

```
合计行：E/G/J 列 = SUM(E30:E204)；H = 1
Rx 行：E/F/G/I/J/M 写 Rx（表示「重新计算」）
A3 行：F='A3'，G/J/M 写与余额表/未审数核对后的值
Diff 行：F='Diff'，G=Rx-A3，J、M 同理，必须为 0
```

`Diff ≠ 0` 就停：先查期间、币别、汇总层、重复账簿，不要改代码。

## 5. Q 列（进一步调查·波动幅度）

```
Q = IF(OR(N="",O=""), IF(ABS(E)>=$C$22,"是（本期达阈值）","否"),
       IF(AND(ABS(N)>=$C$22, ABS(O)>=$C$23),"是","否"))
```

- `C22` = 波动幅度（人民币）= TE × 50%（基准 275,000）；`C23` = 10%
- **C22 取不到就全表失真**：TE 没写进 Lead C4 时 C22=0，`ABS(N)>=0` 恒真，175 行全「是」
- 上期缺失时 N/O 是空字符串，`ABS("")` 会 `#VALUE!`，所以必须先判空
- 明细行用 **AND**（金额与比率都超才标）；表1 的口径汇总用 **OR**（任一超就值得看）

## 6. 表1（按 OAR 口径汇总）

- 标题红字 `C00000`，在框外；表头 6 列：OAR 口径 / 本期审定数 / 上期审定数 / 变动金额 / 变动率 / 是否需调查
- 金额 `SUMIF($T$30:$T$204, $B行, $J$30:$J$204)`；上期 `IF(COUNT($K$30:$K$204)=0,"",SUMIF(...))`，没有上期就留空，**不显示 0**
- 数据行只画左右外框、内部完全无横线；合计行**不加上下边框**
- NB 编号写 **H 列（框外）**，绝不能写进 B 列（B 是 SUMIF 的条件）
- 末尾三行固定：
  - `合计` = 各口径之和
  - `A3` = **主表（BKD）的 A3**，不是本表合计
  - `check` = 本表合计 − 本表 A3，本期、上期各一个，必须为 0
- 写表前把 B~I 整段 `border` 归零再画，否则模板残留横线会让表格右侧叉出一根线

基准（VC）：广告费 18,328,933.79 / 薪酬 14,706,993.23 / 其他 2,360,323.20 / 技术服务费 2,290,142.84 / 折旧摊销 650,280.77，合计 38,336,673.83，check 0/0。

## 7. 表2（变动分析叙述）

- 每段一句，前缀 `NB1：`、`NB2：`…；段间有横线，左右竖线贯通（内外框都要有）
- 金额一律**千元**：`TEXT(值/1000,"#,##0")&" 千元"`
- 内容从序时账摘要提炼（按对方单位/业务类型分组），写不出就如实写「需人工归类」，**不编业务**
- 未超波动的口径也要留一行说明，格式：`·——「薪酬」未超波动范围（275 千元 且 10.0%）`
- 描述拼进公式时：双引号换 `'`、花括号换全角，否则公式报废

## 8. 表3（调整汇总表）

```
B 调整类型 | C 简称 | D 调整说明 | E 科目名称 | F 本期调整数 | G 上期调整数 | H FOR BKD
```

- `I`（本期审计调整）= `SUMIFS($F…, $C…, $A行, $H…, $D行)`
- `L`（上期调整）= `IF(K行="","",SUMIFS($G…, $C…, $A行, $H…, $D行))`
- **FOR BKD 必须与 BKD 的「科目名称」逐字一致**，差一个字符 SUMIFS 就是 0
- 数据区只画左右外框 + 末行底线，内部不画网格（先 `border=Border()` 归零再设）
- 表格行数超出页面底边时，在底边那行**整行插入**让蓝带下移，不能硬画

## 9. 格式红线

- 数字：金额 `#,##0.00;[Red]-#,##0.00`；结构比/变动率 `0.00%`
- 待人工补的格子标黄 `FFFF00`；`P` 列认不出打 `/`，**不标黄**（那是正常结果，不是缺资料）
- 底部蓝带：认「B~H 列 ≥5 格深蓝」的横带，不能扫装饰列（S 列整列深蓝）
- 右侧竖框 + 底边横框要在**明细写完之后**补（模板只铺到固定行，明细一多就断）
- 跨工作簿复制样式不能 `nc._style = c._style`（样式索引错位），必须逐属性 copy

## 10. 坑

| 现象 | 原因 / 处理 |
|---|---|
| 全表「进一步调查」都是「是」 | TE 没写进 Lead C4 → C22=0 |
| `#VALUE!` | 上期为空时直接 `ABS(M)`，要先判空 |
| 合计少算最后一行 | 合计行按写死坐标找，插行后偏了一行；按 D 列「合计」定位 |
| 表1 右侧多一根线 | 模板零散横线没清，写表前 B~I `border` 归零 |
| 表2 只出 4 段就停 | 模板残留 `[A][B]` 合并区冲突，`merge_cells` 抛异常被静默吞掉 |
| 表头灰带断成两截、日期两侧有孤立灰斑 | 插列后新两列是裸格；要在合并 K:M 之前逐格补样式 |
| 上年日期格白底、与本期不对称 | 重建表头时漏了 `fill`（只复制了字体/边框/对齐） |
| 底部蓝带横穿表格 | 算「内容末行」只认有值；改成「有值 **或** 有边框」 |
| 列宽设了又变回去 | 插列搬移被后续列宽覆盖；末尾再钉一次 |
| T 列全「未匹配-待判断」 | 口径Mapping 没建；不许把科目明细名直接当口径（35 个口径 = OAR 退化成罗列） |
