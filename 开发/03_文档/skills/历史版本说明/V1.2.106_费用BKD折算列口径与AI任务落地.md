# V1.2.106 费用 BKD：折算列后的四处修正 + 表2/OAR 真跑 AI

日期：2026-11-12　对象：瑞云 RAYCLOUD 1-9 月（2026-09-30）

## 1. 插列后顶部色带断开（格式 BUG）

`_add_fx_cols` 原来只从表头行往下刷样式，`insert_cols` 新插的两列在**表头以上是空白**，
模板顶部的黑色/灰色分区色带断成「H 列黑、F/G 白」。改为一律从第 1 行刷到末行，
并同时复制填充、字体、边框、对齐与数字格式。校验：第 1 行 E–H 填充签名完全一致，
VC/VD 第 1–39 行逐格比对 0 处不一致。

## 2. 双 0 科目不再列示

- 补行（上年有、本年无）只取上期页**本期未审数 ≠ 0** 的行——之前把上期页里 0 的行也补了进来，
  实测 VC 38 行、VD 34 行「0 / 0」，白占篇幅还像取数漏了。
- 另加 `_drop_zero_rows()` 兜底：本年金额与上年数都为 0 的行剔除（返回剔除行数，进 info.zeroRowsDropped）。
- 结果：VC 220→182 行（补 7 行），VD 173→139 行（补 19 行）；重算后双 0 行 = 0。

## 3. check 区公式没跟列序走

`Diff` 行原写死 `=G合计-G(A3)`、`=J…`、`=M…`，那是插列**前**的「未审/本期审定/上期审定」；
插两列汇率后 G 已是「本年账面数（人民币）」，check 变成「账面合计 − 账面 A3」，永远查不出问题。
现在按新列序生成：未审(I)、本期审定(L)、上期审定(O)，`Rx` 标记同步落在 人民币/账表调整/未审/本期审定 四列。

## 4. 表2 与 OAR 的口径金额差一个汇率倍数

新增 `expense.aud_amount()`：一行本期审定的实体值 = 本币 × 汇率 + 账表调整 + 审计调整。
原因：人民币/未审/审定三列都是公式，openpyxl 读回来是字符串，汇总会得 0 或只读到本币。
表2 原来按本币汇总、OAR 按人民币汇总，同一口径两边差 6.85 倍（宣传推广费 1,731 万 vs 2,157 万）。
统一后：表2 与 OAR 逐口径一致，OAR 合计 = BKD 审定合计（VC 42,792,685.73 / VD 32,506,012.64），
「广告费漏 762,618.76」的差额同步消失。

## 5. 表2 / OAR 变动分析真跑 AI

清单落 `bkd_work/ai_tasks/`，结果写 `*_result.json` 旁路文件，重新生成即生效（不用跑命令）：
- 表2：17 个口径，每段 120–160 字，写「由什么业务/哪家供应商推动、是否一次性、建议什么程序」，不重复金额（金额是公式）
- OAR 变动分析：13 段，40–80 字，只叙述驱动因素
- 口径待判定：3 项（广告和业务宣传费→广告费 0.92、交际应酬费→业务招待费 0.90、办公用品 138 元→其他 0.70）

跑完后 `tasks[]` 与 `warnings` 双双为空；口径 Mapping 来源 = 上年底稿 390 + 由AI判断 3。
