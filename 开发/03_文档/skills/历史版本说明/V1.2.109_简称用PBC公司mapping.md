# V1.2.109：简称一律取客户 PBC「公司mapping」表

日期：2026-11-12　对象：瑞云 RAYCLOUD 1-9 月

## 问题

BKD 的「简称」列原来是程序按字号自己猜的（瑞云 / 瑞影 / RAYWING / 瑞芸有限公司…）：

- 客户 PBC 里本来就有一张「公司mapping」表（编号 / 简称 / 全称 / 2026账簿名称 / 2025账簿名称），
  简称用的是他们自己的口径（`1瑞云母公司`、`4-1上海瑞芸`、`10-1瑞影科技`…），跟我们猜的两套；
- 简称还是「调整汇总表」SUMIFS 的匹配键，两边不一致，
  调整数会取不到，BKD 简称列还会出现「未匹配」；
- 上年底稿的 B 列写的是**2025 年的主体叫法**（`瑞影科技`、`瑞影广州分公司`），
  用 2026 的账簿映射折不动，补行会把这些旧名字直接写进本年 B 列。

## 改法

1. `load_company_map(conn)`：从 `_files` 里认出「公司mapping」那张表（按文件名含 mapping/对照），
   用 `read_xlsx(all_varchar)` 读进来，返回
   - `shorts`：全称 → 简称
   - `books`：账簿名（2026 与 2025 两列都收）→ 全称
   - `compacts`：紧凑键（去地域、去公司性质、去编号/【】）→ 全称，**同键多主体时丢弃**，宁可不折也不折错
2. 「口径Mapping」公司段的简称优先级改为：**PBC 公司mapping > 上年底稿 > 按字号临时猜**，
   备注列直接写明来源（`PBC 公司mapping` / `上年底稿` / `自动提取，可改`）。
3. 搬上期页时折主体的顺序：本年账簿映射 → PBC 的 2025/2026 账簿名 → 归一化 → 紧凑键。
   `瑞影科技`→深圳市瑞影科技有限公司、`瑞影广州分公司`→…广州分公司、`【瑞影】账簿(021)`→深圳市瑞影科技有限公司。
