# 12 · C.00 Lead（科目级汇总）

> 全部是公式，**数不手填**。定不到行号会退回默认行、而 `ok` 仍为 true —— 这是本表最危险的失效方式。

## 1. 科目行怎么找

科目行（库存现金 / 银行存款 / 其他货币资金 / 定期存款 / 大额存单 / 受限资金）由模板语义固定，**行号不固定**：

- 按科目名文字找，**第 1 次出现 = 表1、第 2 次出现 = 表2**；
- 「合计」常写在 E 列而 B/D 是空的 → 扫行要扫到 E 列；
- 日期行找 F 列 `=C3`（或 `=$C$3`）；
- 境外资金找「存放在境外」。

生成后必看 `main.leadRows`：退回默认行号说明模板结构变了，**必须人工核**。

## 2. 表1 的公式结构

```text
期末账面数  = SUMIFS(BKD 折算人民币, BKD 科目, 本行科目)
审计调整    = SUMIFS(调整表金额, 调整表科目, 本行科目)
未审        = 账面 + 账表调整
审定        = 未审 + 调整
变动        = 审定 − 上期
变动%       = 变动 / 上期（上期为 0 时留空，不写 100%）
```

- 程序写的公式**必须同时写缓存值**，否则 `data_only` 读出来全空，人工与下游都拿不到数；
- TB 勾稽行可能由两项相加（如 `T13 + T17`），删项会静默改变结果。

## 3. 封面六格（不写就整张表没有主体）

| 格 | 内容 |
|---|---|
| C2 | 客户名称（表1 账套名列 `=C2`） |
| C3 | 资产负债表日 |
| C4 / C5 | TE / SAD（**先写这两格，再读阈值**） |
| C6 / C7 | 适用会计准则 / 记账本位币 |

不写 C2 → 整表无主体；不写 C3 → 表头单位空、C.03 截止期间无从确定；C4/C5 空 → 认定阈值与 C.03 阈值全错且不报错。

## 4. 上年数（表2 与披露区）

- 表2 上期列 = `SUMIF('上年 C.00 Lead'!科目:金额, 本行科目, 金额列)`；
- 披露区「境外 / 受限」的上期数也链上年 Lead；
- 上年有、本年无的报表科目要**插行**并重指引用；
- 表2 认不到时平台会写 warning —— 此时表2 与披露区可能整块空白，**不能交付**。

> 常见假象：表2 表头是公式（`=J36`），文件若从未被 Excel 打开过就没有缓存值，按文字读会读到空白。平台已按结构兜底，但 warning 仍要人工核一次。

## 5. A3 行与 Diff

- A3 行（审计确认数）默认链接合计；
- `Diff` 三项（账面 / 审定 / 上期）**必须为 0**；
- 不为 0 → 输出「科目 / 预期 / 实际 / 可能原因」，禁止 `+1`/`ROUND` 调平。

## 6. 校验

```text
Σ BKD 折算人民币 == 表1 期末账面数合计
未审 == 账面 + 账表调整
审定 == 未审 + 调整
Diff（账面/审定/上期）== 0
```

用本机 Excel `Ctrl+Alt+F9` 重算后再看这三处，并检查隐藏的 `上年 *` 页有无 `#REF!`/`#N/A`。

## 7. 版式：右侧蓝竖条与底横边必须连续

Lead 最外侧是一圈深蓝装饰带（右竖边 + 底横边）。**插行会把这条带撕开**——新行不继承
邻行的填充，蓝竖条在插入的那几行出现缺口，看起来就是"边缘蓝格被截断"。

平台在写完 Lead 后按当前实际行数补一次（`_paint_outer_frame`）：

- 右竖边认「第 1 行最右边那格是蓝的」；
- 底横边认「第 1 列被涂成深蓝的那一行」；
- 两条带逐格补齐到实际末行/末列；模板本身没有蓝框就什么都不画。

判定：右竖边从第 1 行到合计行下方**不得有缺口**（可用"整列填充色是否连续"检查）。
BKD 用同一函数，原因是它的白底清理循环会把底横边刷掉。
