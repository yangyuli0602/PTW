# 15 · C.03 Cutoff（截止性测试）

> **数据来源是银行流水，不是序时账。** 本期平台尚未接入流水，所以样本区是**有意留空**——不写「未识别到转账」，那会被当成「已经测过、确实没有」。

## 1. 本期平台做什么

| 位置 | 写什么 |
|---|---|
| 阈值 | 测试阈值（覆盖模板原公式），取自 Lead 的 TE 与设定金额 |
| 截止期间 | **强制等于资产负债表日**，不单独传 |
| 说明区 | 日期 / 阈值 / 笔数拼成的一句话，末尾留一句给人补理由 |
| 样本区 | **空**（无流水） |

两个日期必须同源：曾经出现「11-05 取数 / 12-31 找样本 / 真实报表日 09-30」，三个日期互不相同且不报错。

## 2. 接入流水后的口径（预留）

1. 账户范围同 BKD（主体 + 账号 + 币种），按截止期间切片；
2. 按「主体 + 金额 + 日期」找同一笔资金的两条流水（一出、一进，账号不同）；
3. 归表按**付款方日期** ≤ 截止日 → 期末前，> 截止日 → 期末后；
4. 配不上的单边流水进「单边清单」留档，**不许悄悄丢**；
5. 样本区列：样本号 / 公司 / 付款银行 / 付款账号 / 付款日期 / 凭证号 / 币种 / 付款金额(负) / 收款银行 / 收款账号 / 收款日期 / 收款金额(正) / 是否跨期 / 备注 / `=M+I`。

## 3. 为什么不用序时账凑

序时账只有科目、凭证号、金额，看不到收付款双方与到账时间。靠「同凭证号一借一贷」或「跨日金额相等」凑配对，凑出来的是推测：内部调拨、同一账户的两笔不同业务都可能被配成一对。

截止性测试要证的是「钱什么时候真正进出银行」，只有对账单口径的流水能证。

## 4. 校验

```text
P 列（M + I）== 0        （仅在接入流水、有样本时适用）
截止期间 == 资产负债表日
```

无样本时以上两条不适用，但**必须在交付说明里写明「本期未取得流水，C.03 未执行」**，不能让它看起来像已执行。
