# 13 · C.01b 特殊账户程序

> 对象：其他货币资金里的**平台账户 / 保证金 / 第三方支付**等需要单独取证的部分。

## 1. 范围怎么取

- 只取 BKD 中「其他货币资金」且**期末非零**的行；
- 银行账户不进来（银行走函证与对账单，不走这张表）；
- 账户清单必须与 BKD 一致，否则合计对不上。

## 2. 谁填什么

| 列 | 内容 | 来源 |
|---|---|---|
| 账户/平台名称、账号、币种 | 从 BKD 带 | 派生 |
| 账面金额 | 从 BKD 带（**折算人民币列**，与 Lead 口径一致） | 派生 |
| 对账单金额 | 客户资料 | **人工** |
| 账户类型、受限金额、受限原因 | 判断 | **人工** |

## 3. 差异列的写法（踩过）

```text
差异 = IF(I="","", I − G)      ← 对
差异 = I − G                   ← 错：I 空时会算出「差异 = −账面」，看着像少了钱
```

未取得对账单 → 留空标黄，**不填 0**。

## 4. 校验

```text
C.01b 合计 == BKD 其他货币资金合计 − 已单独列示的受限/保证金
```

不等时要解释：是范围没对齐（该进没进）、还是有受限部分被单列。**差异必须解释，不许抹平。**

## 5. 常见失效

| 现象 | 原因 | 处理 |
|---|---|---|
| 整表空 | 该期其他货币资金都函证了，或函证列全标「是」 | 正常，确认 BKD 判读无误即可 |
| 只出一半账户 | 筛条件用了「非零」但账户是 0 余额 | 0 余额账户在 BKD 保留、在本表不进（本表测余额），属正常 |
| 合计差一块 | 受限金额重复列示（BKD 受限列也写了一次） | 回到 Lead 的受限资金行核对口径 |
