# 11 · C.00 BKD（账户级明细）

> 这是唯一「原始录入」的表，后面四张都从它派生。BKD 错，全错。

## 1. 取数口径

只抓一级科目 = `库存现金` / `银行存款` / `其他货币资金`：

- `acct_l1` 精确匹配；为空时兜底 `trim(acct_code)` / `trim(acct_name)`；
- **不用 `LIKE '1002%'`**：会把二级明细重复抓一遍、把名称含「银行」的无关科目带进来；
- 多币别长表：本币只取「综合本位币」行（`end_debit − end_credit`），原币取该账户外币行（`*_fx`）。两者不可同时全取，也不可只取外币行（人民币账户会漏）；
- 金额一律元、两位小数；负数不擅自取绝对值，保留并在 Notes 说明；
- 主体用 `company_name`，空退 `book_name`，再退 `(未标注主体)`；**多主体不过滤**，但每行必须能看出属于谁。

## 2. 写入哪些列

主体、科目、银行/存款机构、账号、币种、原币金额、本币金额、是否函证、Notes、受限资金（人工列）。

- **0 余额、本年销户账户必须保留**（完整性证据），销户信息写 Notes；
- **上年有、本年无的账户也要进表**（金额 0 + Notes 说明），否则证明不了「销户都包含了」；
- 账号单元格设文本格式 `@`（防前导零丢失）；金额 `#,##0.00`；日期 `yyyy-mm-dd`；
- 上年同账户的账号/银行按「科目 + 银行」回捞；取不到留空，**不生成新编号**；
- 银行存款「是否函证」恒为「是」；其他货币资金才需要判断。

## 3. 外币与折算两列

BKD 右侧两列：**折算率**（人工，默认 1）、**折算人民币**（= 本币 × 率）。

- 折算列接在模板已用列最右，**绝不插进模板中间**（插在原币与本币之间会把一对金额劈开）；
- 合计、勾稽、Lead 的 SUMIF 全走折算人民币；
- **合计行三列都有合计数**：原币 / 本币 / 折算人民币（受限列另算）。原币合计只作完整性控制
  （一列混着多种币种，相加不是金额结论），C.02a 的 Check 行会引用它。
- **勾稽行的 Lead 引用按布局现算**：`=折算人民币合计 − 'C.00 Lead'!<当期合计行><账面列>`。
  模板里写死的 F41 是 V7 行号，客户模板插过行（瑞云合计在 46 行）就会指到别的科目上——
  勾稽看着不平、其实是公式指错格。Lead 写完后再回填一次，确保引用的是当期实际行。
- 外币主体拿本币去勾稽必现假差异——这是口径不同，不是错。

### 折算率从哪来：`公司mapping` 页（客户按公司维度给的两列汇率）

客户给的 mapping 表（含「简称 / 全称 / 余额汇率 / 损益汇率」）**原封不动**复制成工作簿里的
`公司mapping` 页，然后：

| 位置 | 写法 |
|---|---|
| BKD **第一列（A）** | `=IFERROR(XLOOKUP(公司全称, 公司mapping!全称列, 公司mapping!简称列),"")`；**只写值，不改该列格式** |
| **折算率列** | `=IFERROR(XLOOKUP(简称, 公司mapping!简称列, 公司mapping!余额汇率列),1)` |

- **余额类科目用余额汇率，损益类用损益汇率**：货币资金全部是余额类；将来放借款/应收应付同样走余额，
  费用/收入/成本才走损益（判断入口 `_rate_kind_of`）。
- mapping 表从**数据目录**取：文件名带 `mapping / 对照 / 汇率` 的 xlsx（根目录或 `uploads/` 都认）；
  工作簿/模板里已有 mapping 页时**优先用现有的**，一格不改。
- 找不到表 → 折算率退回默认 `1`，不猜汇率；结果里会留一条 `公司mapping：…` 的提示。
- 取不到某主体（简称/全称对不上）→ 该行 `IFERROR` 回落 `1`，**不是静默取错值**；
  境外主体要盯一眼折算率是不是真的取到了（瑞云香港/新加坡应为 6.7351 附近，不是 1）。
- mapping 里的小合并/分公司行没有「全称」的，XLOOKUP 自然落空，不影响其它主体。

## 4. 识别列（两年比对）

四段匹配：唯一主键（主体 + 科目 + 银行/账号 + 币种）→ 账号 → 新增 → 本期账面无。

- `matched / newCount / missCount / byKey / byAcct` 要能解释；
- 大额「新增 + 销户」同时出现，先怀疑**账号被规整过**（如 `443…→143…`），不是真新开户；
- 同账户多币种会拆多行（库存现金按币种拆属正常），不要把镜像行当新增。

## 5. 人工列（规则不做，AI 只起草）

| 列 | 内容 | 谁定 |
|---|---|---|
| 折算率 | 按主体填资产负债表日汇率 | 项目组 |
| 性质与用途 | 经营户/保证金/平台余额/存出投资款… | 项目组确认 |
| 受限资金 | 受限金额（同一笔只写一次） | 项目组 |

## 6. 校验

```text
Σ BKD 本币（折算人民币列）== Lead 期末账面数合计
合计行 == SUM(数据区)，且数据区到「合计」行前一行为止
```

- 上年回捞的「性质/用途」若为 `#N/A`/`#REF!`，平台按空处理——**不要把错误值带进本年**；
- 识别列若有整列「本年新增」，先回 `00_总则.md` 阶段2 的四样体检，别在这里硬调。
