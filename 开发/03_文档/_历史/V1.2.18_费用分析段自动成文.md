# V1.2.18 费用 OAR：分析段由工具直接写成业务描述

> 上一版接上了上年数，分析段能算出变动金额与变动率，但正文仍是
> 「主要构成为「A公司」10,907,536.78 元、「B」4,127,032.89 元…」+「【待AI撰写】」。
> 前者是把 BKD 明细抄了一遍，后者等于没写完。本版两处都改掉。

## 1. 从「罗列」改成「按业务性质描述」

**改前**（每一条都是这个形态，黄底等着人工补）：

> 「广告费」…占本类 47.8%。主要构成为「北京视锐达科技有限公司」10,907,536.78 元、
> 「AIGC」4,127,032.89 元、「谷歌广告（上海）有限公司」514,402.98 元。
> 【待AI撰写：变动原因需结合业务判断】请结合上方构成与序时账摘要撰写。

**改后**（工具自己写完，不标黄）：

> 「广告费」本期审定数 18,328,933.79 元，较上期减少 12,982,578.48 元（41.5%），
> 占本类 47.8%。本期全部为市场投放，其中「北京视锐达科技有限公司」一项占六成左右；
> 整体规模较上期明显收缩。

### 怎么做到的

1. **性质归类**（`_NATURE`，10 类）：市场投放 / 股份支付 / 人力成本 / 中介与专业服务 /
   折旧摊销 / 技术服务 / 差旅交通 / 办公及租赁 / 业务招待 / 会议培训。
   词典顺序即优先级——`股份支付` 必须排在 `人力成本` 前面，否则「股权激励」会被
   「员工」这个词抢走，把股份支付写成工资。
2. **占比分母用「本口径本期审定数」**，不是证据之和。证据只取了各科目金额最大的几组，
   拿证据之和当分母会把 30% 写成 80%。
3. **覆盖率门槛**：证据覆盖本口径 ≥ 85% 才说「全部为 X」，否则退成「主要集中于 X」。
4. **单家点名只点一家、且不给金额**：某一家占本口径 ≥ 45% 才点，写成
   「其中「某公司」一项占六成左右」；不到 45% 就写「涉及 N 家主要对手，无单家过半」。
   金额明细在 BKD 的 R 列与 evidence JSON 里可查，正文不复述。
5. **一次性事项**：命中「上市 / 股权激励 / 减值 / 重组 / 诉讼 / 审计调整 / 以前年度 /
   追溯调整」且金额占本口径 ≥ 20% 才提，并按性质分开说（上市相关一次性支出 /
   股份支付确认 / 减值计提 / 重组相关支出 …）。
6. **方向判断**：|Δ%| ≥ 50% 显著、≥ 30% 明显、≥ 10% 有所、更小则「基本持平」。

## 2. 三个「写错比不写更糟」的坑（都已修）

| 坑 | 现象 | 处理 |
|---|---|---|
| 「调整」当一次性词 | 广告费摘要里「调整投放」被写成「属调整性质」 | 一次性词只收强信号，去掉裸「调整」，只留「审计调整 / 以前年度 / 追溯调整」 |
| 「暂估」当一次性词 | 月度计提摘要末尾常带「-暂估」，费用凭空多一句「属暂估或调整性质」 | 从一次性词表移除：它是入账标记，不是事项性质 |
| 性质与事项重复 | 「本期全部为股份支付（即「股权激励」）；该项属股份支付确认」 | 一次性说明与性质同名时不再重复 |

## 3. 标黄条件收紧

- **写出来了就不标黄**（之前只要没人工写结论就整段黄底，复核的人以为还是空白）。
- **写不出来才标黄**：序时账里找不到任何可归类的证据（`_narrate` 返回空）。
- 待确认清单 `pending` 同步收紧：只列**没写出来**的口径，不再把自动写好的也列进去。

## 6. 边界（别指望它替你做判断）

- 描述里的「六成左右」「明显收缩」是**生成时的快照**。BKD 改数后金额/比例会跟着变
  （那部分是公式），但区间词不会——数据大改请重新生成，别手改。
- 工具不写「因为公司今年收缩投放」。那是审计判断，需要业务访谈或管理层说明。
- 摘要里认不出业务类别时，正文会如实写「业务类别需人工归类」并保持黄底，
  不会硬编一个性质。
- 性质词典是中文关键词，纯英文科目名大概率落「其他」（会如实说，不猜）。
