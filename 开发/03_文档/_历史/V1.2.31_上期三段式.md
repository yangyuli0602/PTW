# V1.2.31 上期三段式 + 三处格式

> 用户要求：BKD 里「上期审定数」前面加「上期未审数」「上期调整数」，上期审定 = 前两者相加；
> 上期调整数与本期调整数一样链接下方调整表；调整表两个日期列改口径名；
> 清掉 Notes 列的 `[A][B]`；OAR 口径列按内容展开；底部蓝框只留一行。

## 一、上期三段式（真插两列）

插在「上期审定数」前面，右侧六列整体右移两格：

| 列 | 名称 | 来源 |
|---|---|---|
| K | 上期未审数 | 上年底稿回捞的数（静态值，原 K） |
| L | 上期调整数 | `SUMIFS(调整表 G 列, 简称, FOR BKD)` |
| M | 上期审定数 | `=IF(K="","",K+L)` |
| N | 变动金额 | `=IF(M="","",J-M)` |
| O | 变动% | `=IF(OR(M="",M=0),"",N/M)` |
| P | For X-ref | 原 N |
| Q | 进一步调查（波动） | 原 O |
| R | 进一步调查（定性） | 原 P |
| S | Notes | 原 Q |
| T | OAR 口径 | 原 R |

**插列的三个坑**（openpyxl `insert_cols` 只搬值和样式）：

1. **合并区不跟着走** —— 手工按新坐标重设（跨过插入点的要加宽）。
2. **列宽不跟着走** —— 先记账旧宽度，插完按 `new[c] = old[c-2]` 还原，新两列用原 K 的宽度。
3. **公式不跟着改** —— 数据行由 `_write_formulas` 整体重写；合计行、A3、Diff、表1 的 SUMIF、
   Lead 的链接、OAR 页的 SUMIF 全部按新列字母重写。

**口径说明**：我把上年底稿的上期审定数当作「上期未审数」的起点。调整表里没有上年调整时
L = 0，M 就等于原来的上期审定数（51,660,694.97，与原值逐位相同）。项目组真要区分，
直接在 K 列改成真实未审数、在调整表补上年调整即可，M 会跟着算。

## 二、调整汇总表

两个金额列的表头从 `20260930` / `20251230` 改成 **本期调整数 / 上期调整数**，
与 BKD 列名一致，填的时候不用再想哪个日期对应哪一期。

- I 列（本期调整数）= `SUMIFS($F$…)`
- L 列（上期调整数）= `IF(K="","",SUMIFS($G$…))` —— 上年没这个科目就留空，不写 0

## 三、三处格式

| 位置 | 处理 |
|---|---|
| Notes 列 `[A]`/`[B]` | 模板留的占位（原本指向下面的说明框），生成时按数据区清掉 |
| OAR 口径列 | 按内容最长口径自动展开（中文按 2 个字符宽算，上限 52） |
| 底部蓝框 | 先抹掉所有横贯的深蓝带，只在**内容末行下面补一行**；右侧竖条画到同一行为止 |

蓝框这里踩了一个坑：`content_last` 原来只认「有值的行」，而**调整汇总表整片数据区是空的**，
结果底边画在它第一行上、直接横穿表格。改成「有值 **或** 有边框」才算有内容。

## 五、边界

- 插列是运行时做的，模板文件本身没动。换模板必须保证「上期审定数」这列表头在（`_locate` 靠它定位）。
- 调整表为空时 L 列显示 0.00（公式结果），这是「上年调整为零」而不是「没有数据」——
  若上年确实没有调整，可在调整表把该列留空，`IF(K="")` 会让整行留空。
