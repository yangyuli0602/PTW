# 给使用 PTW 的 AI：操作须知（必读）

> 这份文件是**操作规程**，不是文档导读。文档导读见 `AI先读我_文档路由.md`。
> 你在这里的角色是**操作员**：调用平台产出底稿、核对结果、结清待办。
> **不是开发者**——不要修改 `程序/` 下的任何代码。

## 一、起服务 / 跑生成

两种方式，任选其一：

1. **页面**：双击 `启动PTW平台.bat`，浏览器打开 http://127.0.0.1:8787，首页版本号必须与包名一致。
2. **命令行**（推荐给 AI 用，输出是 JSON，好解析）：

```
程序\runtime\python\python.exe 程序\ptw.py --pretty cash --date 2026-09-30 ^
    --customer "客户名称" --te 550000 --sad 55000 ^
    [--prior "上年BKD底稿.xlsx"] [--prior-lead "上年Lead.xlsx"]
```

## 二、生成后必须做的一件事：结清 tasks[]

返回 JSON 顶层有 `tasks`（清单）和 `blockingTasks`（必须结清的 id）。
**每一条都要标记：已完成 / 无法完成+原因 / 非必需。有 blocking 未结清，不得宣称"完成"。**

| id | 含义 | 怎么结清 |
|---|---|---|
| `c02a-fx-shot` | C.02a 汇率公告截图缺失 | 见第三节 |
| `c01b-statement` | C.01b 未函证账户需对账单 | 向客户取得，填入 I 列 |
| `c02-recon` | C.02 待判断是否存在调节项 | 人工判断后在表内填列 |
| `c00b-equiv` / `c00b-restricted` | 现金等价物范围 / BKD 受限列 | 人工判断或补录后重跑 |

## 三、汇率公告截图（V1.2.92 起默认自动截）

1. 程序会按**资产负债表日**去人行栏目页现查该日公告（会往前翻页），用本机
   Edge/Chrome 无头截该页并自动插入 C.02a。装浏览器的机器不用人管。
2. 目标文件仍是 `data\fx\pbc_20260930.png`（资产负债表日、8 位、无横杠）；
   已存在就直接用、不覆盖——手工补的图优先。
3. 只有这三种情况才需要人工补：
   - 该日**没有**公告（周末/节假日，如 2026-10-01）——不能借用相邻日期；
   - 本机没有 Edge/Chrome，或截图白页/超时；
   - 机器不通外网，定位不到公告页。
   任务卡里会写清是哪一种，并给出该日公告页链接（定位到的话）。
4. **补完必须重新生成一次**，程序会自动把图插到 C.02a 的 Notes 下方，任务随之消失。
5. 常见失效原因：图放错目录、文件名不是 8 位日期、补完没重跑。

## 四、红线

- 不改 `程序/` 代码、不改模板 `data\bkd_tpl\`、不删 `.workbuddy\`。
- 不改底稿里的公式与金额；对不上就如实报告，不要用 `+1`、`ROUND` 之类手法"调平"。
- 判断类字段（性质/用途、是否函证、是否有调节项）**只起草不拍板**，结论由人写。
- 生成前先关掉 Excel 里的同名底稿，否则「_最新」副本会被改名。

## 五、常见坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面打不开 | 服务没起 / 端口被占 | 双击 `启动PTW平台.bat` 重起 |
| 版本号对不上 | 解压到了旧目录 / 开了旧服务 | 换新目录解压，关掉旧服务 |
| C.02a 整表没生成 | 旧包缺 OpenSSL DLL | 用 V1.2.65 及以后的包 |
| 外币汇率全空 | 机器不通外网 | 人工填当日中间价，或换网络重跑 |
| C.01b 是空的 | 该期其他货币资金都函证了，或函证列全标"是" | 正常；确认 BKD 判读无误即可 |
