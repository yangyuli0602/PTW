# V1.2.84 · 上一期底稿只上传一次（TOD 与 BKD 同册）

**来源**：用户反馈「上一期 TOD 就在上一期底稿里面，现在的交互界面居然要我上传两次文件，
没有意义，修改成和货币资金一样」。

货币资金那边一贯是「上年底稿传一份，Lead / OAR / 上年数都从这一份里认」。
费用这边却拆成两个拖拽位（上年度费用底稿 + 上一期 TOD），客户要拖同一个文件两次，
多一次上传、多一次解析，还多一处会选错的地方。

## 问题 → 做法

1. **同一个文件要传两次**
   上一期 TOD 就在上年费用底稿这同一册 WP 里（瑞云：BKD 在第 6/7 页，TOD 在第 9/10 页）。
   → 界面只留一个拖拽位；后端 `probe_prior_all()` 一次 `load_workbook` 同时认两类页，
   返回 `sheets/recVC/recVD` + `tod{sheets,recommended}`。

2. **生成时还得两个 fid**
   → `prior_tod_fid` 缺省即用 `prior_fid` 取原始字节；`prior_tod_sheet` 选定哪张 TOD 页。
   显式传 `prior_tod_fid` 的旧路径仍保留（TOD 单独一册时用）。

3. **TOD 页要人手点一下才算数**
   → 上传后按 `recommended`（优先年审页、其次预审+剩余）自动选中，用户不改就是推荐项；
   文件里没有 TOD 页时明确写「本期预审段按本期阈值从序时账算」，不留空白区。

4. **连带修掉一个网页端硬故障（V1.2.79 遗留）**
   V1.2.79 撤掉「排除Mapping」时删了 `_run_exp(..., excl_map=)` 形参，
   但 `/api/build/exp/run` 与 `/api/build/wp/run` 两个调用点没清 →
   网页点「生成」直接报 `_run_exp() got an unexpected keyword argument 'excl_map'`。
   命令行不走这条路，所以一直没暴露。→ 两处调用参数删除，已实测网页路径可出稿。

## 已知边界

- 上期底稿里**没有** TOD 页时不再报错，直接按本期阈值算预审段（与以前「不传 TOD」的行为一致）。
- 一次上传的文件会**同时**用于「上期审定数回捞」与「上一期 TOD 搬运」；
  若客户的上期数与 TOD 分属两册（少见），仍可用 `--prior-tod` / `prior_tod_fid` 单独指。
- 回归套件（`01_测试/自动回归`）仍是红的，原因同 V1.2.83（旧扁平 import 与陈旧断言），本版未改动相关函数；
  本版判定依据是 `verify_v1284.py`（13 项）+ 两条路径产物逐格比对 + Excel 全量重算。
