## 三、问题 → 做法

### 3.1 上年存账簿名、本年存公司全称，键对不上

上年 BKD 的 B 列是**账簿名**（`RAYWING PTE.LTF.美金`、`【云语】帐簿`），
本年 BKD 写的是**公司全称**（`RAYWING PTE.LTD.`、`深圳市云语科技有限公司`）。
直接拿上年建 mapping，本年一条都匹配不上，会全部落成「待判断」。

做法：建 mapping 前先用 `book_map` 把上年账簿名折成公司全称，再去重。
实测 295 条从「全部待判断」变成「全部命中上年」。

### 3.2 上年口径推导不能丢掉金额

`oar_bucket()` 的「单列大额」是按**科目合计**判断的。第一版推导时没传金额，
结果「中介费」（1,304 万）「股权激励」（385 万）全部掉进「其他」，
OAR 页从 10 个口径缩到 7 个，两项重大口径直接消失。

做法：`read_prior` 读上年 BKD 的「本期账面数」列，按科目名汇总后再推导。

### 3.3 R 列变公式后，OAR 页取不到口径

`expense_oar._buckets_of` 原来直接读 BKD 的 R 列。改成 XLOOKUP 后，
openpyxl 读到的是公式字符串，OAR 页出现「未匹配-待判断」和一堆 0。

做法：`_fill_sheet` 在 Python 侧同时算一份 `bucketByRow`，随 `stats` 传给 OAR，
不再依赖单元格的求值结果。Excel 里 R 列仍是公式，SUMIF 照常工作。

### 3.4 XLOOKUP 的匹配键必须用全称，不能用简称

第一版写成 `$A（简称）|$D（科目）`，而 mapping 的键是 `公司全称|科目`，
所有行都落到兜底值，OAR 只剩一行「未匹配-待判断」。
改成 `$B（账套名称=公司全称）|$D（科目）`。

### 3.5 调整汇总表模板只有「调整类型」一个列头

模板在 BKD 下方给了标题和 B 列的「调整类型」，其余列是空的，
项目组不知道往哪填，审计调整数永远是 0。

做法：按用户提供的图片补齐 7 列：

```
B 调整类型 | C 调整说明 | D 简称 | E 科目名称 | F 20260930 | G 20251230 | H FOR BKD
```

`FOR BKD` 必须填成与 BKD「科目名称」完全一致的值（如 `管理费用_股权激励`），
因为是 SUMIFS 的第二个条件。

### 3.6 负数排除必须排在预提冲销之后

用户明确要求「优先保证预提冲销一一对应排除」。
如果先排负数，一正一负里的负数会被当成「负数」先吃掉，预提冲销配不成对，
报告里的「已识别 N 对」永远对不上。顺序固定为：

```
结转损益 → 薪酬/股权激励/折旧 → 预提冲销（配对） → 负数 → 否
```

### 3.7 AI 判断需要提示词，不能只靠关键词

关键词表能覆盖 80%，但每换一家客户命名就变一次（海柔叫「人力成本_年终奖」，
瑞云叫「绩效/奖金」）。靠字符串命中迟早归错，而口径错会直接导致 OAR 结论错。

所以加了 `03_文档/AI提示词_口径判断.md`，核心几条：

- 口径只能取 6 个（薪酬 / 折旧摊销 / 广告费 / 股权激励 / 单列大额 / 其他）
- **同类必须归并**，差旅费_\* / 办公费_\* / 运输费_\* 一律进「其他」，不许逐个单列
- 单列大额看「整类合计 ≥ 100 万」，不是单行
- 多主体同一业务必须同名同口径
- 不确定就归「其他」并标「需人工确认」，不编新口径

判断结果写进 `data/bkd_work/oar_map_ai.json`，跨年沿用，优先级最高。

## 五、已知边界

1. **XLOOKUP 需要 Excel 2021 / Microsoft 365 或 WPS 新版**。旧版会显示 `#NAME?`。
   本机实测（版本号 12.0，实为 WPS 兼容层）正常求值。若客户用 Excel 2016，
   需要改成 `INDEX+MATCH` —— 一句话的替换，但没做兼容分支。
2. **简称是自动提取的默认值**（去地域、去「有限公司」、去 `PTE.LTD`、分公司取母体字号）。
   遇到「深圳市海柔创新科技集团股份有限公司」这类会得到「海柔」，
   但像「1瑞云母公司」这种审计习惯用法需要人工在 mapping 表里改，改完能沿用。
3. **公司 Mapping 只按公司全称匹配**。同一主体在不同年份全称变更（改名）会匹配不上，
   需要人工在表里补一行。
4. **AI 判断结果落在 `<data>/bkd_work/oar_map_ai.json`**，跟着 `KZ_DATA_DIR` 走。
   换机器不会自动带走，要跟底稿一起备份。
5. 截止性样本池的「负数」是**贷方净额**（借−贷 < 0），包含真实红冲和审计调整冲减；
   大额冲减（如 −299 万）以前会被 `abs()` 门槛选进样本，本版起不再进入。
