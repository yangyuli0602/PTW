## 二、A3 与 check 的取数口径

用户原话："A3 等于上方主表下面的 A3，而不是合计数，check 就是表内合计数减表内 A3，本期上期审定数都要有 check"。

V1.2.29 是 `A3 = 本表合计`，等于把主表的 A3 绕过去了。现在：

```
主表 A3 行（明细下方第 36 行）
  G = G(合计)     J = J(合计)     K = K(合计)      ← 默认链接合计，审计可手改
  审计一改，Diff 行立刻亮出差异，表1 的 A3 跟着变

表1 A3 行
  C = $J$<主表A3行>      本期审定
  D = $K$<主表A3行>      上期审定

表1 check 行
  C = C(合计) − C(A3)          本期
  D = D(合计) − D(A3)          上期
```

瑞云实测（VC 页）：

| | 本期 | 上期 |
|---|---|---|
| 合计 | 38,336,673.83 | 51,660,694.97 |
| A3（引用主表） | 38,336,673.83 | 51,660,694.97 |
| check | **0.00** | **0.00** |
| 主表 Diff | G 0 / J 0 / K 0 | |

VD 页同样：31,975,085.07 / 20,832,935.73，check 0 / 0。
