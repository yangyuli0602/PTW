# V1.2.96 · 综合本位币行在清洗阶段删除

2026-11-10

## 一句话

多币别余额表里那行「综合本位币」在清洗时就删掉，不再带到核对和底稿里。

## 为什么改

**两件事同时成立，所以必须删：**

1. **它和具体币别行是同一笔钱的两个视图。** 瑞云账套实测：TB 里「综合本位币」3127 行、
   「人民币」3364 行、外币若干，同一个科目三种写法并存。本币合计 14.23 亿，
   若把汇总行也算进去会变成 **28.46 亿**（翻倍）。
2. **它看不出具体币别。** 外币金额在汇总行里已经被折平了，留着它对原币核对没有任何
   用处，只会让每一处下游（核对报告、货币资金底稿、银行贷款表）都得再判一次
   「这行算不算数」。判一次就多一个漏判的机会。

清洗阶段删掉，下游就干净了。

## 改了什么

### 新增清洗步骤 `drop_base_cur`

`程序/core/clean.py`

- 币别列命中 `综合本位币 / 本位币 / 记账本位币 / 本币 / 人民币本位币` 的行删掉
- 币别列自动找（`币别 / 币种 / 货币 / currency`），也可以在界面上手动指定
- 被删的行进 `_dropped_<sid>` 表，留痕原因写「综合本位币汇总行（与具体币别行重复，
  且看不出具体币别）」，可逐行溯源
- 排在「删除空行」之后、「删除合计行」之前

### 加进科目余额表的默认预设

`preset("generic", ...)` 的步骤序：去空行 → **删综合本位币** → 删合计/小计 →
删重复表头 → 删页脚 → 去空格 → 整行去重。

银行流水（`_preset_flow`）和固定资产台账（`_preset_fa`）不加 —— 流水没有汇总行，
台账没有币别列，加了也是空转。

## 两道保护

**① 整表都是汇总行时不删。** 如果客户只导出了汇总视图、没有具体币别行，删完就一行
不剩。这种情况保留不删，步骤记录为「整表都是综合本位币行，删掉就没有数据了，保留」——
宁可让人在表里看见，也不能把表清空。清空比翻倍更难查。

**② 没有币别列时不报错。** 固定资产台账、流水这类表没有币别列，步骤自动跳过。

## 影响面

| 对象 | 影响 |
|---|---|
| 已配好清洗方案的老项目 | **不受影响**。步骤存在 `_sheets.clean` 里，不会因为预设变了而自动追加 |
| 新建 / 重选预设的项目 | 自动带上这一步 |
| 固定资产 SWP 底稿 | **零变化**。它读的是已清洗的 `tb` 表，本次只改「清洗这一动作」 |
| `recon.py` 币别归组逻辑 | **不动**。汇总行被删后走「没有汇总行」分支，行为与文档一致 |

老项目想用上新口径，重新选一次预设，或手工加一步「删除综合本位币行」。

## 一处记录纠错

`tmp/test_cur.py` 文件头的注释写着「T-C4 实际输出本位币组 200 且报一致」。
2026-11-10 实跑复核：**实际是「本位币组空、异常 4」**，即配对检查报了 4 个真实差异，
不是「假一致」。原注释与实测不符，已在本版说明里记正。

报出可见差异——所以「静默假一致」这个担心不成立，真正该做的是清洗阶段删干净。
