## 3. 问题 → 做法

### 3.1 综合本位币行：原来「留着再按组区分」，改成「清洗时就删」

**原来错在哪**：多币别账套导出的余额表里，「综合本位币」行是各外币折算后的汇总视图，
和「人民币」「美元」这些具体币别行是**同一批钱的两个视角**。清洗层保留它、指望核对时按组区分，
一旦区分逻辑漏判就是整块翻倍（瑞云实测 14.23 亿 → 28.46 亿），而且这一行**看不出具体币别**，
对原币核对没有任何用处。

**做法**：清洗预设加一步「删除综合本位币行」（命中 `综合本位币 / 本位币 / 记账本位币 / 本币 /
人民币本位币`），被删行进 `_dropped_<sid>` 可逐行溯源。两道保护：

- 整张表都是汇总行（客户只导出了汇总视图）→ 跳过，不清空；
- 没有币别列（台账、流水）→ 跳过，不误删。

`recon.py` **一行未改**：汇总行删掉后自然走「没有汇总行」分支，与文档写的一致。

> 顺带纠正一处记载：`tmp/test_cur.py` 文件头注释写「T-C4 实际输出 200 且报一致」，
> 实跑是「本位币组空 / 异常 4」，即报了 4 个真实差异。原注释与实测不符，该用例已移入 `STALE`。

### 3.2 固定资产 SWP：从「固定行固定列」做到「行与列都由数据决定」

- **表1 变动行**由清单的「新增方式 / 处置方式」决定。瑞云长出「改造转入」「转固冲回」两行，
  模板原有方式一行不删（金额 0 也留一行）。
- **类别列块**由数据决定：模板预留 7 块，客户 4 类就**删净多余 3 块共 9 列**，表2/表3 的 3 行
  空类别一起删，表4 跟着上移。最终表1 = 4 个类别块 + 合计块 + CHECK，20 列，中间无空列。
- **上年 K.01 / 上年 Lead / 原始 TB** 作为隐藏 sheet 沉入底稿，期初与上期数、TB 核对块全走公式
  引用，可点开看来源，不再写死值。
- **类别来源**改为「TB 辅助核算 ∪ 序时账辅助核算」并互校；伪类别（瑞影把科目名塞进辅助核算位，
  出现 `固定资产`/`累计折旧`）两段式过滤。

**为什么删列比插列危险一个量级**：`delete_cols` 只搬格子和样式，公式一个字符都不改。
删完 `Q12` 会变成 `=SUM(…,Q12,…)` 引用自己、`Q18` 去加右侧空区（年末合计恒 0）、表3 指向空
（表3 恒 0、CHECK 恒 0）——**文件能打开、没有错误值、所有差异都是 0**。所以走「删除前快照 →
删除 → 按新坐标三态重建」，引用落在删除区一律抛错，不静默写 `#REF!`。

### 3.3 门禁调整

`test_cur` / `test_exp_layout` / `test_exp_prior` 从 `OFFLINE` 移入 `STALE`。它们的失败原因都是
「断言按旧行为写、实现已改」，V1.2.83/84 就记录过（当时靠 `--force` 发版），留在门禁里只会让每次
回归都是红的，失去哨兵意义。原因与替代验证方式写在 `regress.py` 的注释里。新增 `test_base_cur.py`。
