# 08 · 货币资金底稿运行 SOP（拿到数据就能跑）

> 这份是**操作规程**，不是实现规格。改代码看 `05_货币资金开发手册/`（不在包内）。
> 业务口径看 `02_底稿_货币资金.md`，本文只管「怎么把一份底稿跑出来并证明它对」。
> 目标：换机器、换人、换 AI，只要输入一致，产出逐格一致。

## 0. 一句话流程

```
输入体检 → 参数落齐 → 生成（一条命令）→ 看 6 个返回字段 → 5 条不变量 → Excel 重算 → 逐格比对 → 结清任务卡
```

任何一步不过，**不要往下走、不要宣称完成**。底稿最危险的错是「静默错位」：数字写错行、SUMIF 打空区域，程序照样返回 `ok: true`。

## 1. 输入体检（拿到数据先看这四样，别急着跑）

| # | 查什么 | 怎么看 | 不合格的表现 |
|---|---|---|---|
| 1 | **账户识别键** `aux1` | 货币资金行的 `aux1` 应是「开户行/账户名 + 账号」，且同一账户跨年写法一致 | `aux1` 等于 `company_name`（主体名）→ 两年比对 **0 匹配、全部判「本年新增」** |
| 2 | **原币列** `end_bal_fx` / `end_debit_fx` | 外币户必须有值 | 全空或等于本币 → BKD 原币列失真、C.02a 按 1:1 算，等于作废 |
| 3 | **账号是否被规整过** | 与上年账号集合比对 | 账号改号（如 `443066→143066`）→ 一对假「销户 + 新开户」 |
| 4 | **综合本位币行** | 核对清洗配方里配了 `drop_base_cur` 还是 `keep_base_cur` | 两个都没配、或与上年口径不同 → 金额翻倍或原币列消失 |

```sql
-- 货币资金行的键长什么样（DuckDB）
SELECT acct_l1, aux1, bank_account, currency, end_debit, end_debit_fx
FROM tb WHERE acct_l1 IN ('库存现金','银行存款','其他货币资金') LIMIT 20;
```

体检不过的处理顺序：**回清洗侧修** > 在运行副本上补（补了必须写进说明，不能当无事发生）> 停下来问人。原库与清洗代码一律不动。

## 2. 参数落齐（少一个，结果就不一样）

| 参数 | 缺了会怎样 |
|---|---|
| `--data-dir` | 会直接读写平台自带 `data/`（真实账套），**绝对禁止**；先 `cp` 副本到 `tmp/<日期_任务>/data` |
| `--date` | 封面空白、C.03 无截止期间、汇率公告页找错天 |
| `--customer` | Lead 表头没有主体，整张表看不出是谁的 |
| `--te` / `--sad` | 静默掉到 **10 万 / 1 万**，认定阈值与 Cutoff 阈值全错，只在结果里留 `TE_NOT_READ` |
| `--standard` / `--currency` | 封面「货币/单位:」空白 |
| `--prior` | 无上年明细 → 识别列全空、K 列无上年数，两年比对整块失效 |
| `--prior-lead` | 只影响上年 Lead；同一份文件可同时传给 `--prior` 与 `--prior-lead` |
| 模板 `data/bkd_tpl/` | 缺模板 → `TPL_MISSING`，连 C.02a 都不生成 |
| 浏览器 + 外网 | C.02a 截不到汇率公告页（只留任务卡，不影响金额） |

```bat
程序\runtime\python\python.exe 程序\ptw.py --data-dir "D:\work\data" --pretty cash ^
    --date 2026-09-30 --customer "客户全称" --standard "中国企业会计准则" --currency "人民币" ^
    --te 550000 --sad 55000 ^
    --prior "上年底稿.xlsx" --prior-lead "上年底稿.xlsx" > out.json
```

返回是 JSON（`--pretty` 便于人看）。**别只看最后一行**，按第 4 节读字段。

## 3. 上期底稿的三种坏法（都真实发生过）

| 症状 | 原因 | 处理 |
|---|---|---|
| openpyxl 报 XML/`sharedStrings` 错、打不开 | 脱敏/还原工具替换含 `<si><t>` 字样的文本时没转义 | 用**本机 Excel 打开 → 另存为 .xlsx**（内容不变），用修复后的文件。**不要**自己拼 XML 猜着修 |
| 打开正常，但「性质/用途」「Notes」列是 `#N/A`、`#REF!` | 上年底稿自身就是坏值 | 平台 V1.2.103 起按空处理，不再带进本年；若用的是更早的包，先升级 |
| 表 2 认不到（表2 上年数不链接、披露区空白） | 表 2 表头是**公式**（`=J36`），文件没被 Excel 打开过就没有缓存值 | V1.2.91 起按结构兜底识别；仍认不到会写 warning。看到 warning 必须人工核表 2 |

判定「上期底稿能不能用」的最小检查：`C.00 BKD` 有数据行、明细合计 ≈ `C.00 Lead` 表 1 上年数、有 `C.00 Lead` 表 2。三者不齐就先修文件，别指望平台兜。

## 4. 生成后先看这 6 个字段（就在 JSON 里）

| 字段 | 合格标准 |
|---|---|
| `ok` | `true`（但**不等于**结果对） |
| `main.rows` / `main.amount` | 与 BKD 明细行数、合计自洽 |
| `main.stats` | `matched / newCount / missCount / byKey / byAcct`：对不上就是识别键或上年文件的问题，回到第 1、3 节 |
| `main.derived.c02a` | `status` 正常；`fxSourceKind`（PBC/CFETS）、`fxAnnounceUrl` 有值说明定位到公告页；`warnings` 里的原因要能解释 |
| `main.leadRows` | 写到哪几行。**必须是现场定位的结果**，退回默认行号说明模板结构变了 |
| `tasks[]` / `blockingTasks[]` | `blocking` 未结清 = 这次没做完，不得交付 |

## 5. 五条不变量（生成后必须全过）

```text
Σ BKD 本币（J 列折算人民币） == Lead 期末账面数合计
Lead 未审 == 账面 + 账表调整
Lead 审定 == 未审 + 调整
Lead TB Diff == 0（账面 / 审定 / 上期）
C.02a 末行勾稽 == 0
```

不平就**输出「科目 / 预期 / 实际 / 可能原因」**，禁止 `+1`、`ROUND` 调平、禁止填 0 占位。

## 6. 必须用本机 Excel 真开一次

解析库能读回 ≠ 能用。`openpyxl` 读不到公式缓存值、看不出循环引用、也看不见条件格式被破坏。

- 打开后 `Ctrl+Alt+F9` 全表重算；
- 查三处：隐藏的 `上年 *` 页有没有 `#REF!`/`#N/A`、C.02a 的图形对象在不在、C.00 Lead 的 Diff 是不是 0；
- 有宏/外部链接提示按提示处理，别一律禁用后就说"没问题"。

## 7. 证明「结果一样」：逐格比对，不靠眼看

平台自带比对工具，包内路径 `程序\tools\wp_diff.py`：

```bat
程序\runtime\python\python.exe 程序\tools\wp_diff.py 基线.xlsx 新生成.xlsx --json diff.json
```

- 逐格比**公式文本**与**静态值**，另比每张表的图片数量；
- 「检查」页 A2（生成时间 + 数据来源路径）属生成痕迹，自动抹平；绝对路径、版本号也抹平；
- 退出码：`0` 完全一致 / `1` 有差异 / `2` 读文件失败。

**三档「一样」，别混着说**：

| 档 | 判据 |
|---|---|
| 跑通 | 出文件、`ok: true`、5 条不变量过 |
| 金额一致 | 上面 + 关键合计逐项相等（本币合计、上年数、C.02a 勾稽） |
| 逐格一致 | 上面 + `wp_diff.py` 退出码 0 |

只有第三档才能说「同样的结果」。达不到就如实报差异格，**不要说「应该一样」**。

## 8. 结清任务卡（before 交付）

`tasks[]` 每条都要有结论：已完成 / 无法完成 + 原因 / 非必需。

| id | 怎么结 |
|---|---|
| `c02a-fx-shot` | 看图在不在 `data/fx/pbc_YYYYMMDD.png`；补完**必须重新生成一次** |
| `c01b-statement` | 向客户要对账单，填 C.01b I 列 |
| `c02-recon` | 人工判断有无调节项（**无对账单时不得自动下「无调节项」**） |
| `c00b-equiv` / `c00b-restricted` | 人工判现金等价物范围 / 受限金额 |

## 9. 交付时必须一起给的东西

1. 底稿 xlsx（文件名带客户与资产负债表日）；
2. `out.json`（含 warnings / tasks / stats，是这次的口径证据）；
3. 汇率公告截图（若由程序自动截）；
4. 一份说明：**输入是什么、补过什么、哪些格子还是空的、谁要签字**。

空 ≠ 0。未取得资料留空标黄并进待确认清单，**绝不填 0**。
