# 输入清单 · `<客户简称>` · `<资产负债表日>`

> 填这份的目的：半年后有人（或别的 AI）要重跑这一期时，**不用猜**当时喂了什么、改过什么。
> 写完放在 `<客户>_PBC/项目/输入清单.md`，与 `基线.xlsx` 配套。

## 1. 数据

| 项 | 内容 |
|---|---|
| 清洗库 | 路径 + 文件大小 + 是否连 `.wal` |
| `tb` / `journal` 行数 | |
| 货币资金行数 | |
| 期间 | `YYYY-MM` ~ `YYYY-MM` |
| 主体数 | |
| 是否在副本上补过数据 | 补了什么、补了多少行、为什么补（原库不改） |

## 2. 上年底稿

| 项 | 内容 |
|---|---|
| 文件 | 文件名 + 路径 |
| 来源 | 真实上年底稿 / 客户提供 / **模拟** |
| 处理过什么 | 如「脱敏件 sharedStrings 损坏，已用 Excel 另存修复」 |
| 已知问题 | 如「性质列存在 #N/A」「Lead 上年数与 BKD 明细差 2,907.98」 |

## 3. 生成参数

```bat
程序\runtime\python\python.exe 程序\ptw.py --data-dir "<数据目录>" --pretty cash ^
    --date <> --customer "<客户全称>" --standard "中国企业会计准则" --currency "人民币" ^
    --te <> --sad <> --prior "<上年底稿.xlsx>"
```

- TE / SAD 来源：客户提供 / 模板 PMTE / **默认值（需 `--allow-default-te`，必须在交付说明写明）**；
- 是否传 `--prior-lead`：传了 / 用 `--prior` 同一文件。
