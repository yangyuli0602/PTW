1. **PyInstaller 的 `--clean` 会批量删旧 runtime（112 文件）→ 被批量删除保护拦**
   → build.py 改为「临时目录打包 + 旧目录改名 + 新目录改名」，全程只改名不删除。

5. **git `!` 恢复规则对目录不生效**（不会进被忽略目录）→ 需要「目录 + `/**`」两行。
6. **git status 中文路径是八进制转义** → 一律 `-c core.quotepath=false`。
7. 钩子里 Python 路径失效（新结构无 程序/runtime）→ 按优先级找 buildenv/源码 runtime/系统。

## 10:28 v1.3.2 更新后不再多开窗口（09c91b8）
更新流程本来就是「点『立即更新』→ 全自动下载/校验/替换/重启」，**不跳下载页**（没配
`UPDATE_REPO` 时只会提示"未配置更新源"）。修的是重启环节的一个副作用：主程序重启后
照常开窗 → 旧窗口 JS 又 reload 回来 → 两个窗口。
- `launcher.launch_app(no_ui=True)`：更新后那一轮向主程序传 `PTW_NO_UI=1`
- `server._open_ui_later()`：`PTW_NO_UI=1` 先等 20s，有请求（旧窗口连回）就不开；
  一直没请求才补开（防"更新完什么都没有"）
- 新增 `_LAST_REQ` 记最近请求时间；`KZ_NO_BROWSER=1` 仍最高优先
验证：有请求 → 日志"旧窗口已重新连上，不再新开窗口"且无新窗；无请求 → 20s 后补开并正常加载。

### 窗口/更新三态（回答用户常问）
| 场景 | 行为 |
|---|---|
| 双击 PTW.exe | 开一个 Edge app 窗口 |
| 已有实例再双击 | 复用端口，再开一个窗口（旧行为，未改） |
| 点「检查更新」有新版本 → 「立即更新」 | 自动完成，不跳下载页；旧窗口自己刷回，不新开 |
