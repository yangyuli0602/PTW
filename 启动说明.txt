PTW 平台 · 使用说明
================================================================

一、启动
  双击 PTW.exe。界面会在一个独立窗口里打开（Edge 的 app 模式，没有地址栏/标签页，
  任务栏是单独的窗口；机器上没 Edge 时退回默认浏览器，地址 http://127.0.0.1:8787）。
  退出：点界面右上角「退出」，或在任务栏关掉那个窗口后再点一次 PTW.exe 会提示已退出。
  直接关窗口不会立即停服务（后台还在跑），要彻底停就用顶部「退出」按钮。

二、目录说明（不要删、不要改名）
  PTW.exe            启动器（检查更新、拉起主程序，永不更新）
  runtime\           主程序。升级时整个目录被替换，不要往里放自己的文件
  data\              你的数据，全部在这里：
      ledger.duckdb      账套数据库
      bkd_tpl\           底稿模板（可替换成客户版模板）
      uploads\ bkd_out\  导入件与生成件
      logs\              运行日志
      settings.json      AI 设置（含 Key，只存本机）
  update_pending.json 有更新已下载待应用时的标记（正常不用管）

三、日志（出问题时用这个）
  界面右上角「日志」→ 可直接看最近运行记录，点「下载日志包」得到一个 zip
  （内含全部日志 + 环境信息 + 脱敏后的设置），把它发给技术支持即可定位。

四、AI 助手（可选，默认关闭）
  界面右上角「AI 助手」→ 选择服务商 → 填 API Key → 保存 → 测试连接。
  · 智谱 GLM-4.7-Flash：需到 open.bigmodel.cn 注册取 Key（有免费额度）
  · 自定义：任何 OpenAI 兼容接口（本地 Ollama、公司网关都可）
  开启后可一键产出：口径归类 / 底稿表2 结论 / OAR 变动分析。
  AI 只写文字与分类，金额与比例始终由程序计算。不填 Key 也能用全部非 AI 功能。

五、检查更新
  界面右上角「检查更新」→ 有新版本会显示更新说明 →
  点「立即更新」自动下载、校验、替换并重启，无需其他操作。
  · 数据目录不受影响
  · 内网环境连不上 GitHub 时，会在弹窗里逐个列出更新源的失败原因

六、常见问题
  1) 双击没反应：看 data\logs\launcher.log；多半是杀毒软件拦了 exe。
  2) 提示端口被占用：程序会自动往后找端口，看界面地址栏实际端口。
  3) 提示数据库被占用：确认没有另一个 PTW 窗口在跑；必要时删除
     data\server.lock 后重试。
  4) 底稿生成报「找不到模板」：确认 data\bkd_tpl\ 下有 xlsx 模板；
     换客户模板时保持文件名与模板内表头不变。

七、卸载
  删除整个程序目录即可（data\ 里是你的数据，需要保留就先拷出来）。
